# EarthKind NGO Platform

EarthKind is a full-stack NGO discovery and management platform connecting communities with verified nonprofit organizations, projects, volunteer opportunities, events, and donations.

## Project documentation

The complete setup, architecture, environment configuration, API reference, Render deployment guide, security notes, and production release checklist are maintained in:

**[EarthKind project README](./build-a-full-stack-highly-animated/README.md)**

## Live deployment

- Frontend: https://earthkind-ngo.onrender.com/
- Backend API: https://ngo-pi3s.onrender.com

## Repository layout

- `build-a-full-stack-highly-animated/frontend/` — static website
- `build-a-full-stack-highly-animated/backend/` — Express API, MongoDB models, authentication, NGO workflows, and payment routes

Please read the project README before running locally or deploying. Never commit real credentials or production secrets.
